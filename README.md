# Job Portal - Full Stack Web Application

## Description
Job Portal is a full-stack web application for posting and applying to job vacancies.<br/>
It allows users to create accounts, browse and search for jobs, filter by employment type, location, and remote options, and track their applications via a candidate dashboard.<br/>
The backend is implemented in Java with Spring Boot, and the frontend uses Thymeleaf templates integrated with Spring MVC.

## Features
- User registration and authentication (Spring Security)
- Candidate dashboard to view and manage job applications
- Job search with filters: employment type, location, remote options, date posted
- Admin functionality to post and manage job vacancies
- Role-based access control
- Integration between backend and frontend via Thymeleaf
- Responsive design using Bootstrap and Font Awesome

## Tech Stack
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Spring Data REST
- Spring Security + Thymeleaf extras
- Lombok
- REST APIs
- MySQL
- Maven
- Bootstrap, jQuery, Font Awesome
- DevTools for hot reload during development

## Architecture
- Layered architecture: Controller → Service → Repository
- DTOs for API responses
- Role-based security
- Database integration with MySQL
